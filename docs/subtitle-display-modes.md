# Subtitle display toolbar

The transcript header has three icon controls: subtitle display mode, download PDF, and auto-follow. Each has an accessible name, native title, and a tooltip on hover or keyboard focus. Auto-follow uses aria-pressed; the selected state retains the extension's existing purple palette. Fixed 32px controls keep the toolbar stable in narrow panels.

Clicking the subtitle control cycles bilingual → source only → hidden → bilingual. This is stored using existing showChinese and the new hideSubtitles setting (false by default). Hidden mode retains the panel header/toolbar but publishes an empty sentence list and hides the video overlay; YouTube's native captions remain suppressed while the extension's caption session is active. Source mode publishes source text without translations, errors, or per-row translate actions.

Both non-bilingual modes gate current-line translation, playback prefetch, viewport prefetch and explicit study-translation requests. A display-mode change aborts the old caption session's translation signal, resets pending/queued work and establishes a new session signal while retaining source captions. Returning to bilingual resumes translation. Existing translation visibility shortcuts go through the same settings-change path. Loading source captions still occurs so playback position and source mode work; no translation provider is invoked in hidden/source mode.
