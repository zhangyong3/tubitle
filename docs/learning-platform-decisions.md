# Tubitle 英语学习平台决策

确认日期：2026 年 11 月 16 日。

## 产品方向

面向有一定英语基础的学习者，把观看 YouTube 视频、查词、理解难句和后续复习连接起来。保留原视频及句子播放位置，在网页中支持重复观看、听写和 shadowing。

学习流程为：观看并收藏词句，完成日常小复习，再通过周期性总结和新语境阅读巩固。查询记录是学习线索，不直接代表用户不会或已经掌握。

## 两档收费

| 能力 | 免费版 | 付费版 |
| --- | --- | --- |
| 双语字幕 | 每日上限 500 句 | 提供高于免费版的额度 |
| 离线词典 | 提供基础能力 | 提供基础能力 |
| 单句循环、调速、隐藏中文 | 提供 | 提供 |
| 收藏词句与基础复习 | 提供基础能力 | 完整历史与跨设备同步 |
| AI 语境解释与难句解析 | 少量体验额度 | 更高额度 |
| 听写与 shadowing | 基础流程体验 | 个性化训练、记录和反馈 |
| PDF | 基础打印或样例体验 | 个性化复习册、答案与批注 |
| 周期总结与新语境练习 | 样例或首次体验 | 持续个性化生成 |

不承诺无限 AI 使用。付费版付费字幕具体额度、订阅价格和其他体验边界尚未确定。AI 解析免费版每天 3 次、Pro 每天 100 次，北京时间零点重置，失败不扣次。

每日额度的重置时区、句子计数与去重规则、失败请求及缓存命中是否计数，也尚未确定；每日 500 句不能直接解释为 500 次网络请求。

## 实施顺序

1. 利用现有扩展验证收藏词句、视频位置和次日基础复习。
2. 验证 AI 体验、个性化练习和复习册的付费价值。
3. 建设账户、同步与网页版复习，支持听写和 shadowing。
4. 根据查询与练习结果，提供周期总结和新故事、对话等阅读材料。

## 后续设计约束

- 基础观看保留无需登录的体验，云端同步应说明上传内容，并提供删除和导出入口。
- 新增云端服务时同步更新 README 中现有的本地存储、密钥和隐私说明。
- 免费字幕成本与付费用户成本分别核算。
- 核实字幕获取、内容留存、PDF 导出和离线词典分发的授权边界。
- 网页复习优先采用原视频嵌入与时间定位，视频失效时说明原因。

本文记录已确认的产品方向，不代表这些功能已经实现，也不是完整实施规格。

## 自动采集与登录

同一 Chrome 浏览器登录网站后，插件自动上传在视频中产生的查词和完整句子分析。未登录不上传，不补传匿名历史。网页仅管理这些记录，不提供手动新增。没有连接码、手动连接或历史补传功能；退出登录停止同步，切换账户清除旧账户上传队列。
