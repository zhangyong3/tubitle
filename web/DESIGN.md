# Tubitle design

## Theme

A quiet learning notebook: warm paper, charcoal ink, terracotta emphasis. Product demonstrations carry the first screen; no invented testimonials or usage statistics.

## Palette

Canvas: oklch(0.98 0.008 80). Ink: oklch(0.25 0.015 50). Accent: oklch(0.51 0.14 40). Muted surface: oklch(0.94 0.012 80). Success uses the existing semantic green treatment.

## Typography

System sans with PingFang SC for interface and Chinese. Source Serif 4 with Songti SC for English learning material. Display 48–68px; section titles 30–40px; body 16px, Chinese line-height 1.8. No negative tracking on Chinese.

## Components

Reuse template SiteHeader, SiteFooter, AppLayout, form fields and shadcn primitives. Button radius 8px; inputs 6px; lesson preview 16px. Visible hover and focus, disabled states; minimum 40px targets.

## Layout

Marketing width 1152px, asymmetric split hero, generous section dividers. Personal library prioritizes search, filters, saved text and source links. Spacing uses 4/8/12/16/24/32/48/80px.

## Depth

Flat paper sections, one raised product demonstration. Sidebar uses a distinct muted surface. Avoid repeated shadow cards.

## Guardrails

Label example content. Show upcoming Pro features honestly. Never present an unconfigured payment as purchasable. No decorative gradients, glass surfaces or fake charts.

## Responsive

Desktop split collapses below 900px. Library controls wrap; forms become one column below 640px. Test 390px, 768px and 1440px. Respect reduced motion.

## Future changes

Use system sans 16px/1.8 for explanation text. Use Source Serif 4 24px/1.5 for an English example. Use semantic primary for important actions and an 8px radius. Build filters as inline buttons, not a new modal.
