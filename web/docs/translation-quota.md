# 实时双语字幕每日额度

2026-11-26 套餐调整后，登录用户（Free / Pro）不再执行双语字幕每日句数限制，旧的 `translation_free_daily_limit` 和 `translation_pro_daily_limit` 配置只保留兼容，不再显示于后台设置。

匿名服务请求仍按 IP 执行 `translation_guest_daily_limit`，默认 100 句，按北京时间每天 00:00 重置；0 表示关闭匿名额度。超额返回 HTTP 401、`LOGIN_REQUIRED`，提示登录。用户自选的 Chrome 本地或第三方翻译引擎不消耗此服务器额度。

Free 学习库每天新增 5 条、最多保留 100 条，AI 解析每天 2 次；Pro 学习库记录数不限，AI 解析每天 100 次，并支持旁批转述稿 PDF 下载。基础复习仍可免费使用。

学习库新增和 AI 解析按用户注册时记录的 IANA 时区在当地零点重置，兼容夏令时；已注册账号及缺失、无效时区使用原来的 `Asia/Shanghai`。时区由浏览器在邮件注册、社交登录发起时通过同站 Cookie 传递，只在用户创建时写入，不允许通过个人资料接口更改。服务端当前时间仍作为计数时钟。

学习库重试与词典快照补充不重复计数；删除记录释放总存储空间，但不退还当天新增次数。既有超过 100 条的免费账号保留原有记录，新建时要求删除部分记录或升级。额度拦截只影响服务器学习库同步，本地查词历史继续保留。

时区字段的增量迁移位于 `web/migrations/{sqlite,postgres,mysql}/20261126_registration_timezone.sql`，SQLite 文件也适用于 D1/Turso。生产环境必须在部署代码前审核并应用相应迁移；不要把全新数据库的建表 SQL 直接应用到现有生产库。此次修改未迁移生产数据库。

## 数据与数据库开销

`translation_quota` 仅存 `id`、`day`、`used`。标识是使用 AUTH_SECRET 对日期和 IP 或账号计算的 HMAC-SHA256，每天变化，不保存明文 IP、字幕、视频、时间明细或每次使用历史。当天首次计数时删除旧日记录，清理使用 day 索引；无流量期间不运行额外任务。

SQLite、D1、Postgres 使用一次有条件 UPSERT 预留 5 句，后续从实例内存扣减，通常每 5 句一次计数数据库操作。最后不足 5 句时按 1 句预留，以支持任意整数限额。MySQL 通过原子事务预留，数据库操作数略多。超额结果缓存到当日结束或额度配置变化，避免重复访问计数表。翻译配置最多每分钟读库一次，匿名无 Cookie 请求不查询会话。

预留是保守计数：预取、上游失败、实例回收或内存条目淘汰都可能使已预留的额度没有实际展示；回收一个实例最多损失该身份 4 句剩余额度。多实例累计预留仍不能超过每日上限。这一取舍减少数据库访问，不提供精确的已播放字幕句数统计。已缓存的译文、平台官方双语字幕和用户自行配置的本地服务不消耗服务器额度。

## 部署

新增表需在生产部署前使用对应数据库的 schema 模板运行 `pnpm db:generate`，审核生成 SQL 后运行 `pnpm db:migrate`。开发 SQLite 已同步。不需要写入初始额度配置，未配置时自动使用默认值。

生产入口必须由可信反向代理覆盖 IP 请求头，并禁止绕过代理直接访问源站。优先使用 Cloudflare 的 `cf-connecting-ip`，其次是代理的 `x-real-ip` / `x-forwarded-for`。无法获得有效 IP 时不开放匿名翻译。AUTH_SECRET 必须稳定；更换它会更换当前计数标识。

## 扩展顶部信息栏

未登录时显示有下划线的登录链接；未登录触发 AI 解析时，登录错误也集中显示在此处。登录后显示用户名、今日播放过的字幕句数、累计学习时长（HH:MM:SS）。这是本浏览器的学习统计，与服务器翻译预取配额的计数口径不同。

播放统计在有字幕的正常播放期间累计，跳转、暂停、缓冲和翻译预取不增加学习时长。每 15 秒及暂停时只合并保存到浏览器本地，不发网络请求；信息栏每 15 秒及窗口获得焦点时读取本地缓存，不再逐次校验账号。首次进入及必要的账号校验最多每十分钟一次；存在待同步统计时，由统计上传响应同时更新账号信息。

扩展后台使用十分钟 alarm 汇总上传；离开 YouTube 页面或关闭播放过的 YouTube 标签页时额外触发补传。后台 worker 的普通唤醒不提前上传、不重置已有十分钟 alarm。断网、上传失败或浏览器被强制退出时保留本地累计值，下次定时触发或浏览器启动时重试；完全退出浏览器时不能保证最后一次网络请求完成。

`POST /api/extension/learning` 的 `type: activity` 请求每批最多携带七天累计值。`learning_activity` 只保存按账号、浏览器随机标识和日期汇总的句数与时长，不存字幕、视频 ID 或逐次播放事件，不占用学习库记录额度。服务器使用累计最大值 UPSERT，重试、重复退出事件及乱序响应不会重复累加。账号切换时不把旧账号的统计同步到新账号。当前页面的句子去重集合仍只保存在内存，今日统计日期仍沿用原来的北京时间口径，与注册时区的业务额度独立。

部署前需审核并应用 `web/migrations/{sqlite,postgres,mysql}/20261126_learning_activity.sql`；本机开发 SQLite 已应用此迁移；没有修改生产数据库。
