# 实时双语字幕每日额度

Web 后台「Subtitle Translation」提供三个配置，均按北京时间每天 00:00 重置：

| 配置 | 默认值 | 计数维度 |
| --- | --- | --- |
| `translation_guest_daily_limit` | 100 | IP |
| `translation_free_daily_limit` | 500 | 免费登录账号 |
| `translation_pro_daily_limit` | 5000 | Pro 登录账号 |

0 表示不允许该类用户请求服务翻译。配置保存会清除当前实例缓存；其他实例最多 60 秒更新。套餐判断沿用有效 Pro 订阅规则，最多缓存 60 秒。

匿名超额返回 HTTP 401，`LOGIN_REQUIRED`，文案为「今日匿名双语翻译额度已用完，请登录Tubitle开启更高额度」。扩展直接在字幕区域显示该错误，不弹出提示框或自动打开登录页。免费登录用户超额返回 HTTP 403，`QUOTA_EXHAUSTED`，文案为「今日免费双语翻译额度已耗尽，请升级为Pro开启更高额度」。Pro 超额提示明日再试。

## 数据与数据库开销

`translation_quota` 仅存 `id`、`day`、`used`。标识是使用 AUTH_SECRET 对日期和 IP 或账号计算的 HMAC-SHA256，每天变化，不保存明文 IP、字幕、视频、时间明细或每次使用历史。当天首次计数时删除旧日记录，清理使用 day 索引；无流量期间不运行额外任务。

SQLite、D1、Postgres 使用一次有条件 UPSERT 预留 5 句，后续从实例内存扣减，通常每 5 句一次计数数据库操作。最后不足 5 句时按 1 句预留，以支持任意整数限额。MySQL 通过原子事务预留，数据库操作数略多。超额结果缓存到当日结束或额度配置变化，避免重复访问计数表。翻译配置最多每分钟读库一次，匿名无 Cookie 请求不查询会话。

预留是保守计数：预取、上游失败、实例回收或内存条目淘汰都可能使已预留的额度没有实际展示；回收一个实例最多损失该身份 4 句剩余额度。多实例累计预留仍不能超过每日上限。这一取舍减少数据库访问，不提供精确的已播放字幕句数统计。已缓存的译文、平台官方双语字幕和用户自行配置的本地服务不消耗服务器额度。

## 部署

新增表需在生产部署前使用对应数据库的 schema 模板运行 `pnpm db:generate`，审核生成 SQL 后运行 `pnpm db:migrate`。开发 SQLite 已同步。不需要写入初始额度配置，未配置时自动使用默认值。

生产入口必须由可信反向代理覆盖 IP 请求头，并禁止绕过代理直接访问源站。优先使用 Cloudflare 的 `cf-connecting-ip`，其次是代理的 `x-real-ip` / `x-forwarded-for`。无法获得有效 IP 时不开放匿名翻译。AUTH_SECRET 必须稳定；更换它会更换当前计数标识。

## 扩展顶部信息栏

未登录时显示有下划线的登录链接；未登录触发 AI 解析时，登录错误也集中显示在此处。登录后显示用户名、今日播放过的字幕句数、累计学习时长（HH:MM:SS）。这是本浏览器的学习统计，与服务器翻译预取配额的计数口径不同。

播放统计在有字幕的正常播放期间累计，跳转、暂停、缓冲和翻译预取不增加学习时长。每 15 秒及暂停时合并上报至扩展后台，只在浏览器存储当天各账号的句数与时长汇总，不写入 Web 数据库，也不跨设备同步。页面中的当日句子去重集合只保存在内存中。信息栏每 15 秒及窗口获得焦点时刷新账号状态，按北京时间每天重置统计。
